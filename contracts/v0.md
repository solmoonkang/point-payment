# 킵페이 ↔ 제로페이 연동 규격 v0

> 코드 기준: `packages/contract/src/` (zod) · 예시: `contracts/fixtures/v0.json`
> 로컬 시나리오용 초안이다. 실제 제로페이 · 쿠콘 규격이 나오면 이 문서와 계약 패키지를 함께 고친다.

## 1. 역할 나눔

| 단계 | 제로페이 | 킵페이 |
|---|---|---|
| 노출 | 킵페이 상품 링크 | - |
| 이동 | 일회용 값을 붙여 킵페이로 보냄 | 일회용 값을 제로페이 회원 번호로 교환 |
| 상품 선택 · 가입 | - | 예시 1~5, 킵페이 회원 저장 (제로페이 회원 번호 포함) |
| 결제 | 잔액 응답, 회원의 결제 승인, 차감, 승인 번호 발급 | 예시 6, 사용 요청, 부족 금액 PG 결제, 주문 저장 |
| 취소 | 사용 취소 처리 | 가입 취소 시작, PG 취소, 사용 취소 요청 |
| 대조 | 사용 내역 제공 | 승인 번호로 대조 |

## 2. 공통 규칙

| 항목 | 규칙 |
|---|---|
| 가맹점 확인 | 모든 호출에 `x-merchant-key` 헤더 |
| 금액 | 원 단위 정수, 0 이상 |
| 잔액 계산 | 제로페이만 함. 킵페이는 쓸 금액만 보내고 남은 잔액을 보내지 않음 |
| 같은 요청 다시 보내기 | 사용 요청은 `requestId`가 같으면 처음 만든 사용 건을 그대로 돌려줌. 내용이 다르면 `conflict` |
| 사용 취소 | 같은 사용 건에 두 번 와도 한 번만 복원 |
| 실패 응답 | `{ code, error, message }` — code 는 큰 분류(`unauthorized` · `not-found` · `invalid` · `conflict` · `expired` · `unavailable`), error 는 보낸 쪽의 세부 이름(예: `REQUEST_ID_REUSED`). 다시 보내도 되는 것은 `unavailable` 뿐 |

## 3. 호출 다섯 가지

| 호출 | 경로 | 보내는 값 | 받는 값 |
|---|---|---|---|
| 회원 번호 교환 | `POST /api/v0/link/exchange` | `code` | `memberId`, `name` |
| 잔액 조회 | `GET /api/v0/members/:memberId/balance` | - | `balance`, `expiresOn` |
| 사용 요청 | `POST /api/v0/usages` | `requestId`, `memberId`, `amount`, `merchantOrderId`, `returnUrl` | 사용 건 (`status: pending`, `approvalUrl`) |
| 사용 건 조회 | `GET /api/v0/usages/:usageId` | - | 사용 건 (`status`, `approvalNo`) |
| 사용 취소 | `POST /api/v0/usages/:usageId/cancel` | - | 사용 건 (`status: cancelled`) |
| 사용 내역 | `GET /api/v0/usages?from=&to=` | 기간 | 사용 건 목록 |

사용 건의 상태는 `pending`(회원 승인 대기) · `approved`(차감 완료) · `rejected`(거절: `insufficient` · `expired` · `declined`) · `cancelled`(사용 취소)다.

## 4. 결제 한 건의 순서

```
회원  제로페이에서 「킵페이 보험」 누름
제로페이  일회용 값 발급 → 킵페이 첫 화면 ?code= 로 보냄
킵페이  회원 번호 교환 → 가입 → 잔액 조회 → 사용 요청 (approvalUrl 받음)
회원  제로페이 승인 화면에서 결제 비밀번호 입력
제로페이  차감 · 승인 번호 발급 → returnUrl 로 돌려보냄
킵페이  사용 건 조회로 승인 확인 → 부족 금액 PG 결제 → 가입 완료
        (PG 실패 시 사용 취소로 상품권 복원)
```

## 5. 실제 연동에서 확인할 것

- 링크에 일회용 회원 값을 실을 수 있는지 (교환 호출이 있는지)
- 회원 결제 승인을 제로페이 화면에서 하는지
- 승인 번호 형식과 정산 파일 형식
